# Project Idea 1: Model Checker
A way to check what model wrote a certain bit of writing
### High Level Technical Overview: 
A user inputs the writing they want to check. Then the software parses the data and uses an algorithm to determine what is what and return the model is believs generated a given text.
    
# Project Idea 2: Parking Space Notifier
A way for good samaritans to notify car owners when their car is parked illegal and that they are going to get a ticket (Getting tickets has become a problem in the madison suburbs after they introduced a new street cleaning system and this could be a way for neigbors to easily help other neighbors)
### High Level Technical Overview: 
You take a photo of a license plate, type in the license plate, take a photo of the street sign, and send it to a number (would make use of Twilio or something similar). Then the software processes this info and finds the corresponding info. The software then texts the owner and notifies them to move their car before they get a ticket. 

# Project Idea 3:  Library Space checker
A way to check how many people are at certain study spots
### High Level Technical Overview: 
Scrape data from google maps, wifi, and uw websites to determine how many people are at a study spot then display this info on a website
    
# Project Idea 4: Computer Science version of gartic phone
Code gets passed from person to person and you have to add onto it with a time limit, but you don't get to talk to each other. Then at the end you see what you made.
### High Level Technical Overview: 
All done on a website. One person types in code with a timer, and once the timer is up the code is then shipped to the next person to begin. Once everyone has contributed the code is cleaned up using AI to ensure it runs and the users get to see what they made.
